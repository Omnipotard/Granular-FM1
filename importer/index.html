Importer des sons

Envoie tes propres sons dans le FM-1 qui joue GRAINE, par le câble USB : ils vont dans les emplacements U1 à U4, restent après l'extinction, et deviennent des sources à granuler comme les autres. Cette page marche dans Chrome ou Edge.

Choisis un son, puis branche le FM-1 avec un câble USB.

1. Le son

Dépose un fichier audio ici (WAV, MP3, OGG, FLAC, M4A…)

2. Où le mettre

  • Le FM-1 doit jouer GRAINE (pas son firmware d'origine) : installe-le d'abord.
  • Le son s'arrête quelques secondes pendant l'écriture. Un envoi interrompu laisse l'emplacement vide, jamais un demi-son.
  • Le silence du début est coupé, le son est normalisé puis gardé en 8 bits µ-law, le format des sources de GRAINE.
  • Sans navigateur : python3 tools/graine_import.py son.wav --slot 1 dans le dépôt de GRAINE.
