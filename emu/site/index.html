Prise en main

  1. 1Joue. Les touches jouent le nuage. SELECT change la source, PRESETS parcourt les 16 sons, OCT−/+ l'octave.
  2. 2Sculpte. Les quatre knobs gardent leur couleur sur chaque page : position, taille, densité, flou. Retape HOME pour la page JEU (hauteur, essaim, envers, stéréo).
  3. 3Anime. Maintiens LFO ou ENV et tourne un knob : il est modulé. OCT−/+ pendant le maintien change de source (LFO 2, vélocité, pression, aléa, molette).
  4. 4Joue en live. SEQ ouvre le TAPIS : les 16 touches blanches sont 16 endroits du son, les 11 noires des pads (gel, envers, octaves, bégaie, écho…). ALGORITHM règle la vitesse de lecture : 0 fige, ×1 lit en temps réel. Maintiens HOME pour geler.
  5. 5Récolte. REC enregistre ce que tu joues : ça devient une source à granuler. REC+SAVE la garde dans U1–U4.
  6. 6Gestes. Maintiens REC et tourne un knob : ton geste tourne en boucle sur l'horloge. REC+OCT− efface. Sur GLO, la page HASARD lance les dés (et revient en arrière).

À la souris, un clic droit (ou Maj+clic) sur un bouton le garde enfoncé : c'est ainsi qu'on maintient LFO en tournant un knob. Sur téléphone, deux doigts suffisent.
